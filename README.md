# Sziget-Baracsi Ingatlan – 43 aktív hirdetés

Ez a verzió már tartalmazza mind a 43 aktív ingatlant:
- valódi ár
- alapterület
- szobaszám
- telekméret, ahol van
- valódi ingatlan.com főképlink
- eredeti ingatlan.com hirdetéslink

## Főoldal
Csak az 50 000 000 Ft vagy annál drágább aktív ingatlanok jelennek meg kiemeltként.

## Eladó ingatlanok
Az összes 43 aktív hirdetés megjelenik.

## Kirakati kijelző
A /display/ nézet az összes aktív hirdetést forgatja.

## Új hirdetés később
Mivel az ingatlan.com a közvetlen automatizált scrapert 403-mal blokkolja, új hirdetésnél a biztos munkamenet:
1. add hozzá a linket az active.txt-hez,
2. add meg a linket ChatGPT-ben,
3. frissíthető a properties.json új rekorddal.

A weboldal továbbra is teljesen GitHub Pages-en fut, külön backend nélkül.
