SAJÁT KIRAKATI REKLÁM KÉP HOZZÁADÁSA

1. Másold ide a JPG/PNG képet, pl.:
   eladna-ingatlanat.jpg

2. A display/ads.json fájlba adj hozzá:

{
  "active": true,
  "type": "image",
  "image": "ads/eladna-ingatlanat.jpg",
  "alt": "Eladná ingatlanát?"
}

A kijelző automatikusan beilleszti a körforgásba.
